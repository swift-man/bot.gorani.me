## v0.10.3 · 2026-03-19
### 출석 캘린더 개선
- 이제 캘린더 이미지 하단에 오픈톡방이름, 사용자 닉네임을 표기하여 누구의 출석 정보인지 표기합니다.

### 랭킹 명령어 개선
- 명령어 /랭킹
  - 별명 기능이 활성화된 방은 랭킹 명령어 조회 리스트에 닉네임 (별명) 이 같이 표기됩니다.
  - 별명이 없으면 기존대로 닉네임만 표기됩니다.

## v0.10.2 · 2026-03-18
## AI 모델 성능 개선
- 여러 개의 요청이 동시에 들어왔을 때 처리되는 속도를 개선했습니다.

### 닉네임 변경 감지 기능
- 닉네임을 자주 변경하는 유저의 경우 닉네임 변경 캐치 시 도배가 되는 문제로 이제 특정방은 닉네임 변경 시 닉네임 변경 히스토리가 노출되지 않습니다.
  - 퇴장 시 변경 히스토리는 그대로 나갑니다.

### 밈 자동 답변 기능 변경 
- 특정 방은 밈 기능을 제외합니다. 
  - 채팅의 흐름이 방해될 시 말씀 주시면 제외해 드립니다. 
- 같은 밈이 감지되는 쿨타임을 5분 -> 30분으로 조정하였습니다.

### 특정 고유 이미지 노출 기능
- 명령어 /기도
  - 요청 주신 이미지가 답변으로 나가도록 기능이 추가되었습니다.
  - 특정 방 전용 기능입니다.

### 정보 기능 노출 란에 최근 입장 시간 추가
- 명령어 /정보 닉, 대댓글은 /정보
  - 특정 방 전용 기능입니다.

## v0.10.1 · 2026-03-17
### AI 답변 모델 개선
- 이제 "소띠 운세 알려줘"라고 명령하면 즉시 소띠 운세를 보여줍니다.
- 사용자의 오타를 그대로 전송하는 문제를 개선했습니다.
- 오픈채팅방마다 다른 AI 명칭인데, 페르소나가 흔들리는 문제를 개선했습니다.
- 연동 가능한 채팅방 정보 및 실행 가능한 명령어의 수는 아직 적습니다만, 점진적으로 많이 참고할 수 있도록 파인튜닝을 통한 확장 예정입니다.

## v0.10.0 · 2026-03-16
### AI 답변 모델 변경 안내
- 이제 AI의 답변이 채팅방 정보 및 실행 가능한 명령어를 참고하여 답변합니다.
  - 도입 첫 사례라 답변 품질이 낮을 수 있습니다만 계속 개선할 예정입니다.
  - 기존에 사용하던 "~욥" 체는 사용하지 않습니다.
  - 응답이 이전 모델보다 늦을 수 있습니다.
  - 현재 모델이 오류가 나면 기존 모델로 답이 나갑니다.
  - 잘못된 응답은 제보시주면 답변이 잘 나갈 수 있도록 개선하겠습니다.
